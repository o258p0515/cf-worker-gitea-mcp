### Latest changes
- `get_repository_tree`: resolves `HEAD`/missing SHA via repository default branch and branch commit SHA.
- `get_file_contents`: falls back from unavailable Contents API to Git Trees + Git Blobs and returns decoded UTF-8.
- `get_dir_contents`: falls back to Git Trees and returns immediate directory children.
- `project_read`/`project_write`: corrected repository-scoped paths and now return an explicit `supported:false` capability result if the upstream Gitea Projects API returns 404. The current Gitea instance does return 404 for the Projects API, so project operations are an upstream capability limitation, not a Worker transport failure.
- `actions_run_read.list_workflows`: falls back to discovering workflow files from Git Trees if the upstream Actions workflow-list API returns 404/500; run metadata, jobs and logs still require the upstream Actions API.
